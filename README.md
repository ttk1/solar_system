# 太陽系シミュレーター

NASA/JPL の実データを初期値に、太陽系の8惑星＋月＋太陽の運動を重力多体問題として数値積分で動かすブラウザアプリです。ビルド不要の単一 HTML ファイルで動きます。

![deps](https://img.shields.io/badge/Three.js-0.161.0-green)

> **精度について（要約）**
> 2000年1月1日の実際の天体配置を出発点に、固定の暦データを使わず物理計算だけで動かします。次の惑星直列（2161年5月）や東京から見える次の日食（2030年6月1日）を実際の暦と一致する精度で再現しますが、**鑑賞・学習が目的であり、精密な天体位置の計算用途には向きません**。詳細は[精度と既知の制約](#精度と既知の制約)へ。

## はじめかた

モダンブラウザ（Chrome / Edge / Firefox / Safari）と、Three.js を CDN から読み込むためのインターネット接続が必要です。

地球の地表テクスチャをローカルから読み込むため、**簡易 HTTP サーバー経由での起動を推奨**します。

```sh
# このディレクトリで
python -m http.server
# → ブラウザで http://localhost:8000/ を開く
```

`file://`（ファイルをダブルクリック）でも動きますが、ブラウザによってはローカル画像の読み込みがブロックされ、地球が手続き生成テクスチャ（フォールバック）で表示されることがあります。

## 操作方法

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 視点の回転 |
| 右ドラッグ | 視点の平行移動（パン） |
| マウスホイール | 拡大・縮小（ズーム） |
| タッチ（スマホ） | ドラッグで回転 / 2本指で移動・ズーム |
| 天体名をクリック | その天体を中心にして追従（凡例・画面上のラベルどちらでも）。再クリックで解除。天体のサイズに合わせてズームも自動調整 |
| Space キー | 一時停止 / 再生 |
| Esc キー | 天体の追従を解除（地表モード中はモード終了） |

## 設定パネル（画面左上）

「時間」「表示」「天体」「🎲 面白機能」のセクションに分かれています。ヘッダの ▾ ボタンで全体を折りたたみでき、狭い画面では初期状態で折りたたまれます。

### 時間

- **日付表示** — シミュレーション時刻に対応する実日時（`YYYY年MM月DD日 HH:MM JST`）と、元期（2000年1月1日）からの経過年数
- **⏸ 一時停止 / ▶ 再生**（Space キーでも可）
- **◀ 逆再生** — 時間を巻き戻す方向に再生します（再クリックで一時停止、▶ 再生で順方向に復帰）。積分は時間対称なので逆回しも順方向と同等の精度です
- **↺ リセット** — 初期状態（元期）に戻し、カメラも既定ビューへ
- **⏩ 現在へ早送り** — 現在の日時まで高速で公転を進めて見せ、到達したら速度を等倍（実時間追従）に切り替え
- **日付入力＋移動** — 指定した日付まで高速移動して一時停止（Enter キーでも移動）。現在より**過去の日付なら逆回し**で巻き戻します（積分は時間対称なので順方向と同等の精度）
- **速度スライダー** — 実時間1秒あたりに進む時間を対数で調整（**等倍〜約 1000 年/秒**、デフォルト **1秒 = 1年**）。プリセットボタン（等倍 / 1日/秒 / 1年/秒 / 100年/秒）でワンタッチ設定も可能

### 表示（トグルスイッチ）

- **トレイル** — 軌道の軌跡の表示 ON/OFF
- **天体名** — 天体名ラベルの表示 ON/OFF
- **背景の星** — 星空背景の表示 ON/OFF。実在の恒星カタログ（[HYG Database](https://www.astronexus.com/projects/hyg) 由来、肉眼で見える V≤6.5 の約9,000星）を実際の位置・明るさ・色（B-V色指数から黒体近似）で描画します。固有運動も反映するため、数百年〜千年単位で動かすと星座がわずかに歪みます。`stars.json` が読み込めない環境（`file://` 直開き等）ではランダム生成の星空にフォールバックします
- **高画質 8K** — 地球のテクスチャを 2K → 8K に差し替え（初回 ON 時に遅延読み込み、以後は即時切替）
- **銀河公転** — [後述](#銀河公転モード)
- **実スケール** — 天体を実際の半径比で描画。距離スケールに対して天体は極小（地球で約 0.002 描画ユニット）なのでほぼ点になりますが、天体名をクリックして寄ると球として見えます（カメラの near を小さく＋対数深度バッファで対応）
- **詳細設定**（折りたたみ） — 星の明るさ（星空全体の輝度倍率）、地球の自転位相（昼の経度）と軸の向き（季節）の微調整スライダー。既定値で合わせ済み

### 天体

天体チップをクリックするとその天体を中心に追従します（再クリックまたは Esc で解除）。追従中の天体はハイライトされます。

### 🔗 共有リンク

パネル最下部の「共有リンクをコピー」で、**現在の日時と設定を URL にしてコピー**できます。開いた側では同じ設定が復元され、指定の日時まで早送り（過去なら逆回し）して一時停止します。

- **天体の位置情報は URL に載せていません**。日時だけを渡し、受け取った側が元期からシミュレーションを回して同じ配置を再現します（日時さえ決まれば全天体の状態が一意に決まる、というシミュレーションの性質をそのまま使う設計）。
- パラメータは既定値と異なる設定のみ（表示トグル・速度・追従天体・物理倍率・星の明るさ・地表モードの観測地点と視線方向）。
- 早送りの実時間が長くなりすぎないよう、日時は**元期から±2000年**に制限しています（範囲外の URL は移動せず、設定の復元のみ行います）。

## 銀河公転モード

太陽系が銀河中心を公転している様子を可視化するモードです。

- 物理計算は変えず、描画時に「太陽系原点系」で銀河公転変位を扱います。惑星は常に原点付近に置いて精度を保ち、トレイルだけを公転変位ぶん動かすことで、軌跡がらせん状に流れます。
- 速度は**実スケール**: 銀河公転速度は地球公転速度の約 7.4 倍（≈220 / 29.8 km/s）。実際の軌道半径は桁違いに大きいため、トレイルはほぼ直線的に高速で流れ、**銀河中心は遥か彼方で画面には映りません**（スケール差そのものを体感する設計）。
- 黄道面（惑星の公転面）が銀河面に対し約 63° 傾いている事実も反映しています。

## 🎲 面白機能

実験的な機能をまとめた枠です（折りたたみ可能）。

### 🌍 地表モード

地球の地表（既定: 東京）から空を見上げる視点に切り替えます。

- ドラッグで首振り（スマホは2本指ピンチでズーム）、ホイールで視野角（ズーム）。自転に追従して星空や太陽・月・惑星が流れていきます。星空は実在の恒星カタログによる本物の配置なので、オリオン座や北斗七星など実際の星座が確認できます。
- 観測地点の緯度・経度はスライダーで変更できます。
- 地表からの見え方を正しくするため、モード中は実スケール表示に固定されます（終了時に復元）。
- 速度が速すぎると空の回転で目が回るため、突入時に **1時間/秒** を超える速度は 1時間/秒 まで自動で下がります（モード中・終了後の手動変更は自由）。

**🌑 次の日食へ早送り** — その観測地点から実際に見える次の日食を探索し、**最大食の瞬間まで早送りして一時停止、視点を自動で太陽に向けます**。日付テーブルの参照ではなく、観測点から見た太陽と月の離角が両者の視半径の和を下回るかを物理シミュレーションの状態から直接判定するため、皆既・金環・部分の区別もその場の幾何で決まります（トーストで表示、探索上限20年）。

### 🪐 次の惑星直列へ

8惑星が太陽から見て一定の扇形（90°以内）に集まる「ゆるい直列」の次の時期を**シミュレーション内で計算して探し**、最も集まった瞬間まで早送りして一時停止します。到達後はボタンに日付と集まり角度（spread）を表示します。

- 固定の日付を埋め込むのではなく毎回その場で探すので、太陽質量・重力定数の倍率を変えていても、その条件で実際に集まる瞬間を正しく拾えます。
- 参考: 実際の天文計算では次の本格的な直列は2161年5月ごろ・8惑星が約69°に集まるとされます（[Wikipedia「惑星直列」](https://ja.wikipedia.org/wiki/%E6%83%91%E6%98%9F%E7%9B%B4%E5%88%97)）。本シミュレーションも既定の物理値で **2161-05-19（spread 約 69°）** となり、月単位で一致します。

### ☄ 彗星

- **彗星を発射** — ランダムな高離心率の楕円軌道（実在のものではない）で彗星を1つ放ちます。太陽・各惑星の重力を受けて飛びますが、軽いので惑星側へは影響しません（test particle 扱い）。太陽に近づくと反対方向へ尾が伸びます。同時に最大8個、束縛軌道のため周回し続けます（リセットで全消去）。
- **ランダムに飛来** — ON の間、シミュレーション時間で平均約3年に1個のペースで自動的に飛来します（上限8個で停止）。

### ☀ 物理定数の変更

- **太陽質量 / 重力定数**（各 0〜10倍） — 太陽の引力（太陽の GM のみ）または全天体間の重力（全 GM）の強さを変えて、軌道がどう変わるかを実験できます。0倍は無重力（惑星が直線的に飛び去る）、大きくすると公転が急加速します。「物理を等倍に戻す」で×1.0に復帰。

## 精度と既知の制約

本アプリは**鑑賞・学習を目的**とし、精密な天体位置・暦の計算用途には向きません。

**精度を高めている点**

- 初期値は NASA/JPL HORIZONS（DE441）の実測由来状態ベクトル（元期 2000-01-01、[取得手順](#初期天体データの取得方法nasa-horizons)）
- 重力パラメータ **GM の直接利用**・**惑星系重心質量**・**小惑星摂動**・**一般相対論 1PN 補正**
- **Yoshida 4次シンプレクティック積分**（エネルギー誤差はほぼ倍精度の限界）
- この構成で、次の惑星直列 **2161年5月19日**（実暦: 2161年5月ごろ）、東京から見える次の日食 **2030年6月1日夕方**（実暦と同日）を、固定データなしの物理計算だけで再現します

**割り切っている点**

- 出発点は 2000年1月1日のスナップショットで、そこから数値積分で前後に動かします。26年程度の積分なら内惑星の位置誤差は概ね数〜百 km 台ですが、長期では誤差が累積します。
- 残差は数値積分の粗さではなく、**初期状態ベクトルの微小な不確かさと物理モデルの限界**（内惑星の長期軌道が初期条件に鋭敏）に由来します。NASA/JPL の本格的な暦でも内惑星の長期予測には同種の限界があり、**この程度の誤差は仕様として許容**しています。
- 惑星サイズは見やすさ優先で誇張しています（「実スケール」で実半径比に切替可）。衛星は月のみ（地球の運動の精度向上のため質点として追加）。

## 仕様

### 物理シミュレーション

- **初期状態**: [NASA/JPL HORIZONS](https://ssd.jpl.nasa.gov/horizons/)（DE441）から取得した **元期 2000-01-01 00:00 TDB（JD 2451544.5）** の各天体の**太陽系重心（SSB）基準**状態ベクトル。座標系は黄道面・J2000.0。太陽も SSB に対してわずかに動きます。
- **重力パラメータ**: 質量 m × G ではなく、各天体の**重力パラメータ GM を直接**使用。N 体計算で必要なのは G·m_j の積で、観測から高精度に決まるのは GM のほう（G 単体・m 単体は不確かさが大きい）。**惑星は「惑星系重心」の GM（本体＋衛星）**を採用し、衛星込みの運動を 1 質点で正確に表します（地球・月のみ個別本体の GM）。
- **重力**: ニュートンの万有引力（瞬時作用）＋ **太陽による一般相対論 1PN 補正**（水星の近日点移動の主要因）。
- **摂動天体**: 描画には出しませんが、**冥王星と主要小惑星4個（Ceres・Vesta・Pallas・Hygiea）を重力源として裏で計算**に含めています。高精度天体暦も小惑星を質点として含みます（厳密には小惑星帯全体の質量が要るため主要4個の寄与は小さめですが、より本物に近いモデルにする位置づけ）。
- **積分法**: **Yoshida 4次シンプレクティック積分**（長期のエネルギー保存に優れる）。1ステップ **最大 0.05 日**の可変タイムステップ。100年積分のエネルギー相対誤差は約 10⁻¹⁴ とほぼ倍精度の限界。
- **重心静止系**: 全系の重心（GM 重み）の位置・速度をゼロにして SSB 静止系に合わせます。

### 表示

- **距離スケール**: 実距離を反映（1 AU = 48 描画ユニット）。惑星サイズのみ誇張（実スケール表示で切替可）。
- **見た目**: 手続き生成テクスチャ（斑点、木星・土星の縞）、土星の環、太陽のグロー、軌道トレイル、天体名ラベル。
- **星空背景**: 実在の恒星カタログ（HYG Database 由来、V≤6.5 の約9,000星）。J2000 赤道座標を黄道座標へ変換して天球に配置し、等級から明るさ・大きさ、B-V 色指数から色温度（Ballesteros 近似）→ RGB（黒体近似）で描画。固有運動をシェーダーで適用し、シミュレーション経過年数に応じて星が実際にわずかに動きます。歳差は地球の自転軸と同様に無視（慣性空間固定）。地球のみ実地表テクスチャ＋夜側の街明かりを使用し、昼夜（太陽を向く経度）が表示中の日時に合うよう自転位相を同期しています（均時差などは無視した近似）。
- **自転**: 各惑星の実自転周期（恒星日）でシミュレーション経過時間に連動して回転（金星・天王星は逆行）。自転軸も実際の赤道傾斜角だけ傾き、土星の環はその赤道面に配置。
- **地球の地軸と季節**: 地球の自転軸は慣性空間で一定方向（黄道傾斜 23.44°）に固定しているため、公転に伴って**季節**が再現されます（夏至に北極側が太陽を向いて白夜になる等）。昼夜のターミネーターも傾きを反映します。
- **軌道トレイル**: 先端（現在位置）からの経路距離に応じて減光するグラデーションで、**各天体の軌道約1周ぶんで消えます**。速度を上げても軌跡が際限なく伸びたり何重にも重なったりしません。加算合成のため交差部はわずかに明るく光ります。銀河公転モードでは太陽の軌跡も描き、らせんの全長にわたって減光します。

### 含まれる天体

- **描画する天体**: 太陽、水星、金星、地球、月、火星、木星、土星、天王星、海王星（衛星は地球の月のみ）
- **重力計算にのみ参加する摂動天体**（非表示・直列判定外）: 冥王星、Ceres、Vesta、Pallas、Hygiea

## 初期天体データの取得方法（NASA HORIZONS）

`BODIES[].pos` / `vel` および `PERTURBERS[].pos` / `vel` は [NASA/JPL HORIZONS API](https://ssd-api.jpl.nasa.gov/doc/horizons.html)（DE441）から取得した **元期 2000-01-01 00:00 TDB（JD 2451544.5）** の**太陽系重心（SSB, `@0`）基準**状態ベクトルです。後で再取得・検証できるよう手順を残します。

### API リクエスト

各天体について、以下の URL を取得します（例は地球本体 `COMMAND='399'`）。`OUT_UNITS='KM-S'` で km・km/s で受け取り、コード側で AU・AU/day に換算しています（位置は ÷1.495978707×10⁸、速度は ×86400÷1.495978707×10⁸）。

```
https://ssd.jpl.nasa.gov/api/horizons.api?format=text&COMMAND='399'&EPHEM_TYPE='VECTORS'&CENTER='@0'&TLIST='2451544.5'&OUT_UNITS='KM-S'&VEC_TABLE='2'&REF_PLANE='ECLIPTIC'&OBJ_DATA='NO'
```

主なパラメータの意味:

| パラメータ | 値 | 意味 |
|------------|-----|------|
| `EPHEM_TYPE` | `VECTORS` | 位置・速度の状態ベクトルを出力 |
| `CENTER` | `@0` | 座標原点 = 太陽系重心（SSB）。太陽もこの重心に対して動く |
| `TLIST` | `2451544.5` | 元期 = JD 2451544.5（2000-01-01 00:00 TDB）。出発時刻を変えたいときはここを変更 |
| `OUT_UNITS` | `KM-S` | 単位 = km と km/s（コード側で AU・AU/day へ換算） |
| `REF_PLANE` | `ECLIPTIC` | 基準面 = 黄道面・J2000.0 |
| `VEC_TABLE` | `2` | 位置 + 速度を出力 |

### 惑星は「惑星系重心」を取得する

衛星を個別にシミュレーションせず高精度を保つため、惑星は本体ではなく**惑星系重心（barycenter）**の状態ベクトルを使います（`COMMAND` に水星系 `1`・金星系 `2`・火星系 `4`・木星系 `5`…を指定）。地球・月のみ本体（`399` / `301`）を個別に扱います。質量も同様に「惑星系の GM（本体＋衛星）」を採用しています。

### 重力パラメータ GM

重力計算は質量 (kg) ではなく各天体の **GM（重力パラメータ, km³/s² を ×10⁹ して m³/s²）** を直接使います。出典は JPL DE440/DE441 系の公表値で、惑星は惑星系重心 GM、地球・月は本体単独 GM、主要小惑星は Horizons の `OBJ_DATA` の GM です。

### 天体 ID（`COMMAND`）

| 天体 | ID | 天体 | ID |
|------|----|------|----|
| 太陽 | `10` | 火星系 | `4` |
| 水星系 | `1` | 木星系 | `5` |
| 金星系 | `2` | 土星系 | `6` |
| 地球（本体） | `399` | 天王星系 | `7` |
| 月 | `301` | 海王星系 | `8` |
| 冥王星系 | `9` | 小惑星 | 番号 + `;`（下記） |

惑星は本体 ID（`199`・`299`…）ではなく**惑星系重心 ID（`1`・`2`・`4`…）**を使う点に注意（衛星込みの運動を 1 質点で正確に表すため）。小惑星は番号末尾に `;` を付けます（Ceres `1;`、Pallas `2;`、Vesta `4;`、Hygiea `10;`）。

### 値の読み取り

レスポンス本文の `$$SOE` 〜 `$$EOE` の間に、`X Y Z`（位置 [km]）と `VX VY VZ`（速度 [km/s]）が出力されます。これを AU・AU/day に換算して `BODIES` / `PERTURBERS` の `pos` / `vel` に転記します（コード内では `pos[2]`=Z、`vel` も同順）。

> 補足: 企業プロキシ等で SSL インターセプトがある環境では `curl` が証明書エラーになることがあります。その場合はブラウザで上記 URL を直接開いて本文をコピーするのが手軽です。

## カスタマイズの目安（ソース内の定数）

| 定数 | 場所 | 意味 |
|------|------|------|
| `SCALE` | 描画セクション | 1 AU あたりの描画ユニット数（距離スケール） |
| `PHYS_DT` | 物理セクション | 物理積分の1ステップ上限（デフォルト 0.05 日） |
| `BODIES[].radius` | 天体データ | 各天体の表示用半径（見やすさ優先） |
| `TRAIL_MAX` | 描画セクション | 軌道トレイルの最大頂点数 |
| `TRAIL_SEG` | 描画セクション | トレイルの点を打つ間隔（軌道距離）。表示長は別途「軌道約1周」が上限 |
| `EARTH_PHASE0` | 描画セクション | 地球の自転位相（昼の経度）。画面の調整パネルでも変更可 |
| `EARTH_AXIS_LON` | 描画セクション | 地球の自転軸が倒れる黄経方向（季節の合わせ込み）。画面の調整パネルでも変更可 |
| `OBS_LAT_DEG` / `OBS_LON_DEG` | 地表モードセクション | 地表モードの初期観測地点（既定: 東京）。画面のスライダーでも変更可 |
