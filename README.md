# 太陽系シミュレーター

太陽系の8惑星と太陽の運動を、実際の物理値に基づいてシミュレートするブラウザアプリケーションです。

![deps](https://img.shields.io/badge/Three.js-0.161.0-green)

> **このシミュレーションについて**
> **2026年1月1日の実際の天体配置を出発点**に、重力多体問題を数値積分して天体を動かします。簡易な物理モデルのため、長期間進めると実際の天体暦（NASA の暦など）から**無視できない程度の誤差**が生じます（例: 約160年後の惑星配置で内惑星に数十度のずれ）。**鑑賞・学習を目的としたものであり、この誤差は許容するもの**としています。精密な天体位置の計算には使えません。詳しくは [既知の制約](#既知の制約意図的な割り切り) を参照してください。

## ファイル構成

- [`index.html`](index.html) — 本体（HTML + JavaScript）
- `textures/2k_earth_daymap.jpg` — 地球の地表テクスチャ（[クレジット](#クレジット)参照）

## 動作環境

- モダンなブラウザ（Chrome / Edge / Firefox / Safari）
- インターネット接続（Three.js を CDN から `importmap` で読み込むため）

### 開き方

地球の地表テクスチャをローカルから読み込むため、**簡易 HTTP サーバー経由での起動を推奨**します。

```sh
# 例: このディレクトリで
python -m http.server
# → ブラウザで http://localhost:8000/ を開く
```

`file://`（ファイルをダブルクリック）でも動きますが、ブラウザによってはローカル画像の読み込みがブロックされ、地球が手続き生成テクスチャ（フォールバック）で表示されることがあります。

## 操作方法

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 視点の回転 |
| 右ドラッグ | 視点の平行移動（パン） |
| マウスホイール | 拡大・縮小（ズーム） |
| 天体名をクリック | その天体を中心にして追従（凡例・画面上のラベルどちらでも）。同じ天体を再クリックで解除。天体のサイズに合わせてズームも自動調整 |

### 画面左上のUI

- **日付表示** — 現在のシミュレーション時刻に対応する実日付（`YYYY年MM月DD日`）
- **経過年数** — 元期 (2026年1月1日) からの経過年数
- **シミュレーション速度スライダー** — 実時間1秒あたりに進む時間を対数で調整（**等倍〜約 1000 年/秒**、デフォルト **1秒 = 1年**）。1秒あたりの経過時間と実時間に対する倍速を表示します。
- **⏸ 一時停止 / ▶ 再生**
- **↺ リセット** — 初期状態（元期）に戻す
- **⏩ 現在へ早送り** — 現在の日時まで高速で公転を進めて見せ、到達したら速度を等倍（実時間追従）に切り替えます。
- **日付入力＋移動** — 指定した日付まで高速移動して一時停止します。シミュレーションの現在より**過去の日付なら逆回し**で巻き戻します（積分は時間対称なので順方向と同等の精度）。
- **軌道トレイル表示** — 軌跡の表示 ON/OFF
- **銀河公転モード** — 後述
- **実スケール表示** — 天体を実際の半径比で描画します。距離スケールに対して天体は極小（地球で約 0.002 描画ユニット）なので、ほとんど点になります。天体名をクリックして寄ると球として見えます（カメラの near を小さく＋対数深度バッファで極小天体にも寄れるようにしています）。
- **地球 自転軸の調整**（折りたたみ） — 地球の自転位相（昼の経度）と軸の向き（季節）を微調整するスライダー。既定値で合わせ済みですが、再調整したい場合に使えます。
- **🎲 面白機能**（設定の下の枠） — 後述

## 銀河公転モード

太陽系が銀河中心を公転している様子を可視化するモードです。

- 物理計算は変えず、描画時に「太陽系原点系」で銀河公転変位を扱う方式。惑星は常に原点付近に置いて精度を保ち、トレイルだけを公転変位ぶん動かすことで、軌跡がらせん状に流れます。
- 速度は**実スケール**: 銀河公転速度は地球公転速度の約 7.4 倍（≈220 / 29.8 km/s）。実際の軌道半径は桁違いに大きいため、トレイルはほぼ直線的に高速で流れ、**銀河中心は遥か彼方で画面には映りません**（スケール差そのものを体感する設計）。
- 黄道面（惑星の公転面）は銀河面に対し約 63° 傾いている事実を軌道面の傾きとして反映しています。

## 面白機能

設定パネルの下に、実験的な機能を置く「🎲 面白機能」枠があります。

- **🪐 次の惑星直列へ** — 8惑星が太陽から見て一定の扇形（90°以内）に集まる「ゆるい直列」の次の時期を**シミュレーション内で計算して探し**、その最も集まった瞬間まで早送りして一時停止します。到達後はボタンに日付とそのときの集まり角度（spread）を表示します。
  - 固定の日付（実暦）を使わないのは、簡易シミュレーションでは長期積分の誤差により実暦の配置を正確に再現できないためです。「このシミュレーション内で実際に集まる瞬間」を探すことで、画面上で確実に直列が見えます。
  - 参考: 実際の天文計算では次の本格的な直列は2161年5月ごろ（8惑星が約69°に集まる）とされます（[Wikipedia「惑星直列」](https://ja.wikipedia.org/wiki/%E6%83%91%E6%98%9F%E7%9B%B4%E5%88%97)）。本シミュレーションでも2161年ごろに集まる結果になりますが、角度・日付には積分誤差ぶんの差が出ます。
- **☀ 太陽質量 / 🌌 重力定数の倍率**（各 0〜10倍） — 太陽の質量、または万有引力定数を実際の値の何倍にするかを変えて、軌道がどう変わるかを実験できます。0倍は無重力（惑星が直線的に飛び去る）、大きくすると公転が急加速します。太陽質量は太陽の引力のみ、重力定数は全天体間の重力に作用します。「物理を等倍に戻す」で×1.0に戻せます。
- **☄ 彗星を発射** — ランダムな高離心率の楕円軌道（実在のものではない）で彗星を1つ放ちます。彗星は太陽・各惑星の重力を受けて飛びますが、軽いので惑星側へは影響しません（test particle 扱い）。太陽に近づくと太陽と反対方向に尾を伸ばします。同時に存在できるのは最大8個で、束縛軌道のため太陽を周回し続けます（リセットで全消去）。
- **☄ ランダムに飛来**（チェックボックス） — ON の間、シミュレーション時間で平均約3年に1個のペースで彗星が自動的に飛来します（上限8個に達すると停止）。

## 仕様

### 物理シミュレーション

- **初期状態**: [NASA/JPL HORIZONS](https://ssd.jpl.nasa.gov/horizons/) から取得した **元期 2026-01-01 00:00 TDB（JD 2461041.5）** の各天体のヘリオセントリック（太陽中心）状態ベクトルを使用。座標系は黄道面・J2000.0（「J2000」は座標の基準のことで、出発時刻＝元期は 2026 年）。
- **質量**: 太陽および各惑星の実際の質量 (kg) を使用。
- **重力**: ニュートンの万有引力（瞬時作用、万有引力定数 G = 6.674×10⁻¹¹）。
- **積分法**: **Yoshida 4次シンプレクティック積分**（長期のエネルギー保存に優れる）。1ステップ **最大 0.05 日**の可変タイムステップ（低速時は細かく刻んで等倍まで滑らかに、高速時は分割して進めます）。100年積分のエネルギー相対誤差は約 10⁻¹⁴ とほぼ倍精度の限界。
- **運動量保存**: 系全体の運動量がゼロ（重心が静止）になるよう、太陽の初速で全運動量を相殺。

### 表示

- **距離スケール**: 実距離を反映（1 AU = 48 描画ユニット）。
- **惑星サイズ**: 見やすさを優先し、実スケールではなく誇張した半径で描画。
- **見た目**: 手続き的に生成したテクスチャ（斑点、木星・土星の縞模様）、土星の環、太陽のグロー、星空背景、軌道トレイル、惑星名ラベル。地球のみ実際の地表テクスチャを使用し、昼夜（太陽を向く経度）が表示中の日時にそれっぽく一致するよう自転位相を同期しています（均時差などは無視した近似）。
- **自転**: 各惑星の実際の自転周期（恒星日）に基づき、シミュレーション経過時間に連動して回転（金星・天王星は逆行）。自転軸も実際の赤道傾斜角だけ傾いており、土星の環はその赤道面に配置されます。シミュレーション速度を遅くすると自転も遅くなります。
- **地球の地軸と季節**: 地球の自転軸は慣性空間で一定方向（黄道傾斜 23.44°）に固定されているため、公転に伴って**季節**が生まれます（夏至には北極側が太陽を向いて白夜になるなど）。北極点が回転軸と一致し、昼夜のターミネーターも傾きを反映します。
- **軌道トレイル**: 一定の軌道距離ごとに点を打つため、シミュレーション速度を変えても軌跡の長さがほぼ一定に保たれます。新しい点ほど明るいグラデーションで、先端が流れていくように見えます。銀河公転モードでは太陽（太陽系の代表点）の軌跡も描きます。

### 含まれる天体

太陽、水星、金星、地球、月、火星、木星、土星、天王星、海王星（衛星は地球の月のみ。地球の運動をより正確にするため質点として含めています）。

## 既知の制約（意図的な割り切り）

本アプリは**鑑賞・学習を目的**としており、物理シミュレーションは簡易実装として割り切っています。精密な天体位置・暦の計算用途には向きません。

- **出発点は 2026年1月1日のスナップショット**。そこから数値積分で前後に動かします。
- **長期では実際の天体暦から無視できない程度ずれます**。短中期（数十年）は十分実用的な精度（例: 10年後の地球で約 1°）ですが、長期間進めると内惑星ほど誤差が累積します（約160年後で水星・金星に数十度）。これは数値積分の粗さではなく、**簡易な多体モデルと実際の太陽系の微小な差が、内惑星の鋭敏な（カオス的な）軌道で増幅される**ためで、NASA/JPL の本格的な暦でも内惑星の長期予測には同種の限界があります。**この誤差は仕様として許容**しています。
- 惑星サイズは見やすさ優先で誇張しており、実スケールではありません（「実スケール表示」で実半径比に切替可）。衛星は月のみ（地球の運動の精度向上のため質点として追加）。

## 初期天体データの取得方法（NASA HORIZONS）

`BODIES[].pos` / `vel` は [NASA/JPL HORIZONS API](https://ssd-api.jpl.nasa.gov/doc/horizons.html) から取得した **元期 2026-01-01 00:00 TDB（JD 2461041.5）** の状態ベクトルです。後で再取得・検証できるよう手順を残します。

### API リクエスト

各天体について、以下の URL を取得します（例は地球 `COMMAND='399'`）。

```
https://ssd.jpl.nasa.gov/api/horizons.api?format=text&COMMAND='399'&EPHEM_TYPE='VECTORS'&CENTER='500@10'&TLIST='2461041.5'&OUT_UNITS='AU-D'&VEC_TABLE='2'&REF_PLANE='ECLIPTIC'&REF_SYSTEM='J2000'&OBJ_DATA='NO'
```

主なパラメータの意味:

| パラメータ | 値 | 意味 |
|------------|-----|------|
| `EPHEM_TYPE` | `VECTORS` | 位置・速度の状態ベクトルを出力 |
| `CENTER` | `500@10` | 座標原点 = 太陽中心（ヘリオセントリック） |
| `TLIST` | `2461041.5` | 元期 = JD 2461041.5（2026-01-01 00:00 TDB）。出発時刻を変えたいときはここを変更 |
| `OUT_UNITS` | `AU-D` | 単位 = AU と AU/day |
| `REF_PLANE` | `ECLIPTIC` | 基準面 = 黄道面 |
| `REF_SYSTEM` | `J2000` | 基準座標系 = J2000.0（座標のものさし。出発時刻=元期とは別物） |
| `VEC_TABLE` | `2` | 位置 + 速度を出力 |

### 天体 ID（`COMMAND`）

| 天体 | ID | 天体 | ID |
|------|----|------|----|
| 水星 | `199` | 土星 | `699` |
| 金星 | `299` | 天王星 | `799` |
| 地球 | `399` | 海王星 | `899` |
| 月 | `301` | 火星 | `499` |
| 木星 | `599` | （太陽は中心なので 0,0,0） | — |

### 値の読み取り

レスポンス本文の `$$SOE` 〜 `$$EOE` の間に、`X Y Z`（位置 [AU]）と `VX VY VZ`（速度 [AU/day]）が出力されます。これをそのまま `BODIES` の `pos` / `vel` に転記します（コード内では `pos[2]`=Z、`vel` も同順）。

> 補足: 企業プロキシ等で SSL インターセプトがある環境では `curl` が証明書エラーになることがあります。その場合はブラウザで上記 URL を直接開いて本文をコピーするのが手軽です。

## カスタマイズの目安（ソース内の定数）

| 定数 | 場所 | 意味 |
|------|------|------|
| `SCALE` | 描画セクション | 1 AU あたりの描画ユニット数（距離スケール） |
| `PHYS_DT` | 物理セクション | 物理積分の1ステップ上限（デフォルト 0.05 日） |
| `BODIES[].radius` | 天体データ | 各天体の表示用半径（見やすさ優先） |
| `TRAIL_MAX` | 描画セクション | 軌道トレイルの最大頂点数 |
| `TRAIL_SEG` | 描画セクション | トレイルの点を打つ間隔（軌道距離）。総長 ≈ `TRAIL_SEG × TRAIL_MAX` |
| `EARTH_PHASE0` | 描画セクション | 地球の自転位相（昼の経度）。画面の調整パネルでも変更可 |
| `EARTH_AXIS_LON` | 描画セクション | 地球の自転軸が倒れる黄経方向（季節の合わせ込み）。画面の調整パネルでも変更可 |
