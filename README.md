# 太陽系シミュレーター

太陽系の8惑星と太陽の運動を、実際の物理値に基づいてシミュレートするブラウザアプリケーションです。

![deps](https://img.shields.io/badge/Three.js-0.161.0-green)

> **このシミュレーションについて**
> **2000年1月1日の実際の天体配置を出発点**に、重力多体問題を数値積分して天体を動かします。重力パラメータ GM の直接利用・惑星系重心質量・小惑星摂動・一般相対論 1PN 補正により精度を高めており、次の惑星直列を **2161年5月19日ごろ** と、専門ライブラリや天文計算と月単位で一致する精度で再現します。それでも長期では初期値・物理モデルの限界に由来する誤差は残るため、**鑑賞・学習を目的とし、精密な天体位置の計算用途には向きません**。詳しくは [既知の制約](#既知の制約意図的な割り切り) を参照してください。

## ファイル構成

- [`index.html`](index.html) — 本体（HTML + JavaScript）
- `textures/2k_earth_daymap.jpg` / `2k_earth_nightmap.jpg` — 地球の昼側地表・夜側街明かりテクスチャ（[クレジット](#クレジット)参照）
- `textures/8k_earth_daymap.jpg` / `8k_earth_nightmap.jpg` — 高画質モード用の8K版（同上）

## 動作環境

- モダンなブラウザ（Chrome / Edge / Firefox / Safari）
- インターネット接続（Three.js を CDN から `importmap` で読み込むため）

### 開き方

地球の地表テクスチャをローカルから読み込むため、**簡易 HTTP サーバー経由での起動を推奨**します。

```sh
# 例: このディレクトリで
python -m http.server
# → ブラウザで http://localhost:8000/ を開く
```

`file://`（ファイルをダブルクリック）でも動きますが、ブラウザによってはローカル画像の読み込みがブロックされ、地球が手続き生成テクスチャ（フォールバック）で表示されることがあります。

## 操作方法

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 視点の回転 |
| 右ドラッグ | 視点の平行移動（パン） |

### 画面左上のUI

パネルは「時間」「表示」「天体」「🎲 面白機能」のセクションに分かれています。ヘッダの ▾ ボタンで全体を折りたたみでき、狭い画面では初期状態で折りたたまれます。

**時間セクション**

- **日付表示** — 現在のシミュレーション時刻に対応する実日時（`YYYY年MM月DD日 HH:MM JST`）
- **経過年数** — 元期 (2000年1月1日) からの経過年数
- **⏸ 一時停止 / ▶ 再生**（Space キーでも可）
- **↺ リセット** — 初期状態（元期）に戻し、カメラも既定ビューへ戻します
- **⏩ 現在へ早送り** — 現在の日時まで高速で公転を進めて見せ、到達したら速度を等倍（実時間追従）に切り替えます。
- **日付入力＋移動** — 指定した日付まで高速移動して一時停止します（Enter キーでも移動）。シミュレーションの現在より**過去の日付なら逆回し**で巻き戻します（積分は時間対称なので順方向と同等の精度）。
- **速度スライダー** — 実時間1秒あたりに進む時間を対数で調整（**等倍〜約 1000 年/秒**、デフォルト **1秒 = 1年**）。下の**プリセットボタン**（等倍 / 1日/秒 / 1年/秒 / 100年/秒）でワンタッチ設定もできます。

**表示セクション**（トグルスイッチ）

- **トレイル** — 軌道の軌跡の表示 ON/OFF
- **天体名** — 画面上の天体名ラベルの表示 ON/OFF
- **背景の星** — 星空背景の表示 ON/OFF
- **高画質 8K** — 地球のテクスチャを 2K → 8K に差し替えます（初回 ON 時に遅延読み込みし、以後は即時切替）
- **銀河公転** — 後述
- **実スケール** — 天体を実際の半径比で描画します。距離スケールに対して天体は極小（地球で約 0.002 描画ユニット）なので、ほとんど点になります。天体名をクリックして寄ると球として見えます（カメラの near を小さく＋対数深度バッファで極小天体にも寄れるようにしています）。
- **地球 自転軸の調整**（折りたたみ） — 地球の自転位相（昼の経度）と軸の向き（季節）を微調整するスライダー。既定値で合わせ済みですが、再調整したい場合に使えます。

**天体セクション**

- 天体チップをクリックするとその天体を中心に追従します（再クリックまたは Esc で解除）。追従中の天体はハイライトされます。

**🎲 面白機能セクション** — 後述（折りたたみ可能）

## 銀河公転モード

太陽系が銀河中心を公転している様子を可視化するモードです。

- 物理計算は変えず、描画時に「太陽系原点系」で銀河公転変位を扱う方式。惑星は常に原点付近に置いて精度を保ち、トレイルだけを公転変位ぶん動かすことで、軌跡がらせん状に流れます。
- 速度は**実スケール**: 銀河公転速度は地球公転速度の約 7.4 倍（≈220 / 29.8 km/s）。実際の軌道半径は桁違いに大きいため、トレイルはほぼ直線的に高速で流れ、**銀河中心は遥か彼方で画面には映りません**（スケール差そのものを体感する設計）。
- 黄道面（惑星の公転面）は銀河面に対し約 63° 傾いている事実を軌道面の傾きとして反映しています。

## 面白機能

設定パネルの下に、実験的な機能を置く「🎲 面白機能」枠があります。

- **🌍 地表モード** — 地球の地表（既定: 東京）から空を見上げる視点に切り替えます。ドラッグで首振り、ホイールで視野角（ズーム）を変更。自転に追従して星空や太陽・月・惑星が流れていきます。観測地点の緯度・経度はスライダーで変更できます。地表からの見え方を正しくするため、モード中は実スケール表示に固定されます（終了時に元へ戻ります）。
  - **🌑 次の日食へ早送り** — その観測地点から実際に見える次の日食（月が太陽に重なる瞬間）をシミュレーション内で探索し、**最大食の瞬間まで早送りして一時停止、視点を自動で太陽に向けます**。日付テーブルの参照ではなく、観測点から見た太陽と月の離角が両者の視半径の和を下回るかを物理シミュレーションの状態から直接判定するため、皆既・金環・部分の区別もその場の幾何で決まります（トーストで表示）。探索上限は20年です。
- **🪐 次の惑星直列へ** — 8惑星が太陽から見て一定の扇形（90°以内）に集まる「ゆるい直列」の次の時期を**シミュレーション内で計算して探し**、その最も集まった瞬間まで早送りして一時停止します。到達後はボタンに日付とそのときの集まり角度（spread）を表示します。
  - 固定の日付を埋め込むのではなく毎回シミュレーション内で探すことで、太陽質量・重力定数の倍率を変えたときでも、その条件で実際に集まる瞬間を正しく拾えます。
  - 参考: 実際の天文計算では次の本格的な直列は2161年5月ごろ（8惑星が約69°に集まる）とされます（[Wikipedia「惑星直列」](https://ja.wikipedia.org/wiki/%E6%83%91%E6%98%9F%E7%9B%B4%E5%88%97)）。本シミュレーションは GM 直接利用・惑星系重心質量・小惑星摂動・1PN 一般相対論補正により精度を高めており、既定の物理値（倍率×1.0）で 2000年元期から探索すると **2161-05-19（spread 約 69°）** となり、Wikipedia の「2161年5月ごろ」と月単位で一致します。
- **☀ 太陽質量 / 🌌 重力定数の倍率**（各 0〜10倍） — 太陽の重力、または全体の重力の強さを実際の値の何倍にするかを変えて、軌道がどう変わるかを実験できます。0倍は無重力（惑星が直線的に飛び去る）、大きくすると公転が急加速します。太陽質量は太陽の引力（GM）のみ、重力定数は全天体間の重力（全 GM）に作用します。「物理を等倍に戻す」で×1.0に戻せます。
- **☄ 彗星を発射** — ランダムな高離心率の楕円軌道（実在のものではない）で彗星を1つ放ちます。彗星は太陽・各惑星の重力を受けて飛びますが、軽いので惑星側へは影響しません（test particle 扱い）。太陽に近づくと太陽と反対方向に尾を伸ばします。同時に存在できるのは最大8個で、束縛軌道のため太陽を周回し続けます（リセットで全消去）。
- **☄ ランダムに飛来**（チェックボックス） — ON の間、シミュレーション時間で平均約3年に1個のペースで彗星が自動的に飛来します（上限8個に達すると停止）。

## 仕様

### 物理シミュレーション

- **初期状態**: [NASA/JPL HORIZONS](https://ssd.jpl.nasa.gov/horizons/)（DE441）から取得した **元期 2000-01-01 00:00 TDB（JD 2451544.5）** の各天体の**太陽系重心（SSB）基準**状態ベクトルを使用。座標系は黄道面・J2000.0。太陽も SSB に対してわずかに動きます（重心は全天体で決まる）。
- **重力パラメータ**: 質量 m × G ではなく、各天体の**重力パラメータ GM を直接**使用します。N 体計算で必要なのは G·m_j の積で、観測から高精度に決まるのは GM のほう（G 単体・m 単体は不確かさが大きい）。**惑星は「惑星系重心」の GM（本体＋衛星）**を採用し、衛星込みの運動を 1 質点で正確に表します（地球・月のみ個別本体の GM）。
- **重力**: ニュートンの万有引力（瞬時作用）＋ **太陽による一般相対論 1PN 補正**（水星の近日点移動の主要因）。
- **摂動天体**: 描画には出しませんが、太陽系の質量分布をより忠実にするため、**冥王星と主要小惑星4個（Ceres・Vesta・Pallas・Hygiea）を重力源として裏で計算**に含めています。高精度天体暦も小惑星を質点として含みます（厳密には小惑星帯の影響を完全に再現するには数百個ぶんの連続質量が必要で、主要4個だけの寄与は小さめですが、より本物に近いモデルにする位置づけです）。
- **積分法**: **Yoshida 4次シンプレクティック積分**（長期のエネルギー保存に優れる）。1ステップ **最大 0.05 日**の可変タイムステップ（低速時は細かく刻んで等倍まで滑らかに、高速時は分割して進めます）。100年積分のエネルギー相対誤差は約 10⁻¹⁴ とほぼ倍精度の限界。
- **重心静止系**: 全系の重心（GM 重み）の位置・速度をゼロにして SSB 静止系に合わせます（データ丸めで残る微小ドリフトを除去）。

### 表示

- **距離スケール**: 実距離を反映（1 AU = 48 描画ユニット）。
- **惑星サイズ**: 見やすさを優先し、実スケールではなく誇張した半径で描画。
- **見た目**: 手続き的に生成したテクスチャ（斑点、木星・土星の縞模様）、土星の環、太陽のグロー、星空背景、軌道トレイル、惑星名ラベル。地球のみ実際の地表テクスチャを使用し、昼夜（太陽を向く経度）が表示中の日時にそれっぽく一致するよう自転位相を同期しています（均時差などは無視した近似）。
- **自転**: 各惑星の実際の自転周期（恒星日）に基づき、シミュレーション経過時間に連動して回転（金星・天王星は逆行）。自転軸も実際の赤道傾斜角だけ傾いており、土星の環はその赤道面に配置されます。シミュレーション速度を遅くすると自転も遅くなります。
- **地球の地軸と季節**: 地球の自転軸は慣性空間で一定方向（黄道傾斜 23.44°）に固定されているため、公転に伴って**季節**が生まれます（夏至には北極側が太陽を向いて白夜になるなど）。北極点が回転軸と一致し、昼夜のターミネーターも傾きを反映します。
- **軌道トレイル**: 先端（現在位置）からの経路距離に応じて減光するグラデーションで描き、**各天体の軌道約1周ぶんで消える**ため、シミュレーション速度を上げても軌跡が際限なく伸びたり何重にも重なったりしません。加算合成のため軌跡の交差部はわずかに明るく光ります。銀河公転モードでは太陽（太陽系の代表点）の軌跡も描き、らせんの全長にわたって減光します。

### 含まれる天体

**描画する天体**: 太陽、水星、金星、地球、月、火星、木星、土星、天王星、海王星（衛星は地球の月のみ。地球の運動をより正確にするため質点として含めています）。

**裏で重力計算にのみ参加する摂動天体**（非表示・直列判定外）: 冥王星、Ceres、Vesta、Pallas、Hygiea。外惑星の軌道精度を上げる目的です。

## 既知の制約（意図的な割り切り）

本アプリは**鑑賞・学習を目的**としており、物理シミュレーションは簡易実装として割り切っています。精密な天体位置・暦の計算用途には向きません。

- **出発点は 2000年1月1日のスナップショット**。そこから数値積分で前後に動かします。
- **長期でも実暦とよく一致しますが、無視できない誤差は残ります**。GM 直接利用・惑星系重心質量・小惑星摂動・1PN 一般相対論補正により高い精度を達成しており、26 年（2000→2026）程度の積分なら内惑星の位置誤差は概ね数〜百 km 台に収まります。それでも長期間進めると誤差は累積し、**残差は数値積分の粗さではなく初期状態ベクトルの微小な不確かさや物理モデルの限界に由来**します。NASA/JPL の本格的な暦でも内惑星の長期予測には同種の限界があります。**この程度の誤差は仕様として許容**しています。
- 惑星サイズは見やすさ優先で誇張しており、実スケールではありません（「実スケール表示」で実半径比に切替可）。衛星は月のみ（地球の運動の精度向上のため質点として追加）。

## 初期天体データの取得方法（NASA HORIZONS）

`BODIES[].pos` / `vel` および `PERTURBERS[].pos` / `vel` は [NASA/JPL HORIZONS API](https://ssd-api.jpl.nasa.gov/doc/horizons.html)（DE441）から取得した **元期 2000-01-01 00:00 TDB（JD 2451544.5）** の**太陽系重心（SSB, `@0`）基準**状態ベクトルです。後で再取得・検証できるよう手順を残します。

### API リクエスト

各天体について、以下の URL を取得します（例は地球本体 `COMMAND='399'`）。`OUT_UNITS='KM-S'` で km・km/s で受け取り、コード側で AU・AU/day に換算しています（位置は ÷1.495978707×10⁸、速度は ×86400÷1.495978707×10⁸）。

```
https://ssd.jpl.nasa.gov/api/horizons.api?format=text&COMMAND='399'&EPHEM_TYPE='VECTORS'&CENTER='@0'&TLIST='2451544.5'&OUT_UNITS='KM-S'&VEC_TABLE='2'&REF_PLANE='ECLIPTIC'&OBJ_DATA='NO'
```

主なパラメータの意味:

| パラメータ | 値 | 意味 |
|------------|-----|------|
| `EPHEM_TYPE` | `VECTORS` | 位置・速度の状態ベクトルを出力 |
| `CENTER` | `@0` | 座標原点 = 太陽系重心（SSB）。太陽もこの重心に対して動く |
| `TLIST` | `2451544.5` | 元期 = JD 2451544.5（2000-01-01 00:00 TDB）。出発時刻を変えたいときはここを変更 |
| `OUT_UNITS` | `KM-S` | 単位 = km と km/s（コード側で AU・AU/day へ換算） |
| `REF_PLANE` | `ECLIPTIC` | 基準面 = 黄道面・J2000.0 |
| `VEC_TABLE` | `2` | 位置 + 速度を出力 |

### 惑星は「惑星系重心」を取得する

衛星を個別にシミュレーションせず高精度を保つため、惑星は本体ではなく**惑星系重心（barycenter）**の状態ベクトルを使います（`COMMAND` に水星系 `1`・金星系 `2`・火星系 `4`・木星系 `5`…を指定）。地球・月のみ本体（`399` / `301`）を個別に扱います。質量も同様に「惑星系の GM（本体＋衛星）」を採用しています。

### 重力パラメータ GM

重力計算は質量 (kg) ではなく各天体の **GM（重力パラメータ, km³/s² を ×10⁹ して m³/s²）** を直接使います。出典は JPL DE440/DE441 系の公表値で、惑星は惑星系重心 GM、地球・月は本体単独 GM、主要小惑星は Horizons の `OBJ_DATA` の GM です。

### 天体 ID（`COMMAND`）

| 天体 | ID | 天体 | ID |
|------|----|------|----|
| 太陽 | `10` | 火星系 | `4` |
| 水星系 | `1` | 木星系 | `5` |
| 金星系 | `2` | 土星系 | `6` |
| 地球（本体） | `399` | 天王星系 | `7` |
| 月 | `301` | 海王星系 | `8` |
| 冥王星系 | `9` | 小惑星 | 番号 + `;`（下記） |

惑星は本体 ID（`199`・`299`…）ではなく**惑星系重心 ID（`1`・`2`・`4`…）**を使う点に注意（衛星込みの運動を 1 質点で正確に表すため）。小惑星は番号末尾に `;` を付けます（Ceres `1;`、Pallas `2;`、Vesta `4;`、Hygiea `10;`）。

### 値の読み取り

レスポンス本文の `$$SOE` 〜 `$$EOE` の間に、`X Y Z`（位置 [km]）と `VX VY VZ`（速度 [km/s]）が出力されます。これを AU・AU/day に換算して `BODIES` / `PERTURBERS` の `pos` / `vel` に転記します（コード内では `pos[2]`=Z、`vel` も同順）。

> 補足: 企業プロキシ等で SSL インターセプトがある環境では `curl` が証明書エラーになることがあります。その場合はブラウザで上記 URL を直接開いて本文をコピーするのが手軽です。

## カスタマイズの目安（ソース内の定数）

| 定数 | 場所 | 意味 |
|------|------|------|
| `SCALE` | 描画セクション | 1 AU あたりの描画ユニット数（距離スケール） |
| `PHYS_DT` | 物理セクション | 物理積分の1ステップ上限（デフォルト 0.05 日） |
| `BODIES[].radius` | 天体データ | 各天体の表示用半径（見やすさ優先） |
| `TRAIL_MAX` | 描画セクション | 軌道トレイルの最大頂点数 |
| `TRAIL_SEG` | 描画セクション | トレイルの点を打つ間隔（軌道距離）。総長 ≈ `TRAIL_SEG × TRAIL_MAX` |
| `EARTH_PHASE0` | 描画セクション | 地球の自転位相（昼の経度）。画面の調整パネルでも変更可 |
| `EARTH_AXIS_LON` | 描画セクション | 地球の自転軸が倒れる黄経方向（季節の合わせ込み）。画面の調整パネルでも変更可 |
