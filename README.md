# 太陽系シミュレーター

太陽系の8惑星と太陽の運動を、実際の物理値に基づいてシミュレートする単一HTMLアプリケーションです。
ブラウザで開くだけで動作します。

![type](https://img.shields.io/badge/type-single--file-blue) ![deps](https://img.shields.io/badge/Three.js-0.161.0-green)

## 2つのバージョン

物理シミュレーションは共通で、描画レイヤーだけが異なる2ファイルを用意しています。

| ファイル | 描画 | 備考 |
|----------|------|------|
| [`solar_system.html`](solar_system.html) | Three.js (WebGL) | 標準版。**銀河公転モード**を搭載 |
| [`solar_system_webgpu.html`](solar_system_webgpu.html) | 自前 WebGPU (WGSL) | Three.js 非依存。行列演算・球メッシュ・シェーダ・カメラ操作をライブラリなしで実装 |

両者ともテクスチャ・土星の環・惑星名ラベルなど見た目は同等です。

## 動作環境

- **Three.js 版**: モダンなブラウザ（Chrome / Edge / Firefox / Safari）+ インターネット接続（Three.js を CDN から `importmap` で読み込むため）
- **WebGPU 版**: WebGPU 対応ブラウザ（Chrome / Edge 113+ など）。非対応時は日本語のエラー画面を表示

サーバーは不要。HTML ファイルをダブルクリックして開くだけです。

## 操作方法

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 視点の回転 |
| 右ドラッグ | 視点の平行移動（パン） |
| マウスホイール | 拡大・縮小（ズーム） |

### 画面左上のUI

- **日付表示** — 現在のシミュレーション時刻に対応する実日付（`YYYY年MM月DD日`）
- **経過年数** — 元期 (J2000) からの経過年数
- **シミュレーション速度スライダー** — 実時間1秒あたりに進む年数を対数で調整（**約 0.01 〜 1000 年/秒**、デフォルト **1秒 = 1年**）
- **⏸ 一時停止 / ▶ 再生**
- **↺ リセット** — 初期状態（元期）に戻す
- **重力伝播遅延** — 光速での重力伝播遅延の ON/OFF（デフォルト ON）
- **軌道トレイル表示** — 軌跡の表示 ON/OFF
- **銀河公転モード**（Three.js 版のみ） — 後述

## 銀河公転モード（Three.js 版）

太陽系が銀河中心を公転している様子を可視化するモードです。

- 物理計算は変えず、描画時に「太陽系原点系」で銀河公転変位を扱う方式。惑星は常に原点付近に置いて精度を保ち、トレイルだけを公転変位ぶん動かすことで、軌跡がらせん状に流れます。
- 速度は**実スケール**: 銀河公転速度は地球公転速度の約 7.4 倍（≈220 / 29.8 km/s）。実際の軌道半径は桁違いに大きいため、トレイルはほぼ直線的に高速で流れ、**銀河中心は遥か彼方で画面には映りません**（スケール差そのものを体感する設計）。
- 黄道面（惑星の公転面）は銀河面に対し約 63° 傾いている事実を軌道面の傾きとして反映しています。

## 仕様

### 物理シミュレーション

- **初期状態**: [NASA/JPL HORIZONS](https://ssd.jpl.nasa.gov/horizons/) から取得した **J2000 元期（2000-01-01 12:00 TDB, JD 2451545.0）** の各天体のヘリオセントリック（太陽中心・黄道面 J2000）状態ベクトルを使用。
- **質量**: 太陽および各惑星の実際の質量 (kg) を使用。
- **重力**: ニュートンの万有引力（万有引力定数 G = 6.674×10⁻¹¹）。
- **積分法**: velocity Verlet（リープフロッグ）、固定タイムステップ **0.5 日**。
- **重力伝播遅延**: 各天体の位置履歴をリングバッファで保持し、`距離 / 光速` だけ過去の位置から受ける力を計算。
- **運動量保存**: 系全体の運動量がゼロ（重心が静止）になるよう、太陽の初速で全運動量を相殺。

### 表示

- **距離スケール**: 実距離を反映（1 AU = 40 描画ユニット）。
- **惑星サイズ**: 見やすさを優先し、実スケールではなく誇張した半径で描画。
- **見た目**: 手続き的に生成したテクスチャ（斑点、木星・土星の縞模様）、土星の環、太陽のグロー、星空背景、軌道トレイル、惑星名ラベル。
- **自転**: 見栄え用の固定速度で回転（実際の自転周期ではない）。

### 含まれる天体

太陽、水星、金星、地球、火星、木星、土星、天王星、海王星（衛星は含まない）。

## 既知の制約（意図的な割り切り）

物理シミュレーションは簡易実装として割り切っています。

- 初期状態は元期のスナップショットであり、簡易な積分のため長期間進めると実際の天体暦から徐々にずれます。
- 重力伝播遅延は「現在位置で距離を見積もってから遅延位置を参照する」一次近似です（反復解は行いません）。
- 惑星の自転は実際の自転周期を反映していません。

## 初期天体データの取得方法（NASA HORIZONS）

`BODIES[].pos` / `vel` は [NASA/JPL HORIZONS API](https://ssd-api.jpl.nasa.gov/doc/horizons.html) から取得した J2000 元期の状態ベクトルです。後で再取得・検証できるよう手順を残します。

### API リクエスト

各天体について、以下の URL を取得します（例は地球 `COMMAND='399'`）。

```
https://ssd.jpl.nasa.gov/api/horizons.api?format=text&COMMAND='399'&EPHEM_TYPE='VECTORS'&CENTER='500@10'&TLIST='2451545.0'&OUT_UNITS='AU-D'&VEC_TABLE='2'&REF_PLANE='ECLIPTIC'&REF_SYSTEM='J2000'&OBJ_DATA='NO'
```

主なパラメータの意味:

| パラメータ | 値 | 意味 |
|------------|-----|------|
| `EPHEM_TYPE` | `VECTORS` | 位置・速度の状態ベクトルを出力 |
| `CENTER` | `500@10` | 座標原点 = 太陽中心（ヘリオセントリック） |
| `TLIST` | `2451545.0` | 元期 = J2000（JD 2451545.0 = 2000-01-01 12:00 TDB） |
| `OUT_UNITS` | `AU-D` | 単位 = AU と AU/day |
| `REF_PLANE` | `ECLIPTIC` | 基準面 = 黄道面 |
| `REF_SYSTEM` | `J2000` | 基準座標系 = J2000 |
| `VEC_TABLE` | `2` | 位置 + 速度を出力 |

### 天体 ID（`COMMAND`）

| 天体 | ID | 天体 | ID |
|------|----|------|----|
| 水星 | `199` | 土星 | `699` |
| 金星 | `299` | 天王星 | `799` |
| 地球 | `399` | 海王星 | `899` |
| 火星 | `499` | （太陽は中心なので 0,0,0） | — |
| 木星 | `599` | | |

### 値の読み取り

レスポンス本文の `$$SOE` 〜 `$$EOE` の間に、`X Y Z`（位置 [AU]）と `VX VY VZ`（速度 [AU/day]）が出力されます。これをそのまま `BODIES` の `pos` / `vel` に転記します（コード内では `pos[2]`=Z、`vel` も同順）。

> 補足: 企業プロキシ等で SSL インターセプトがある環境では `curl` が証明書エラーになることがあります。その場合はブラウザで上記 URL を直接開いて本文をコピーするのが手軽です。

## カスタマイズの目安（ソース内の定数）

| 定数 | 場所 | 意味 |
|------|------|------|
| `SCALE` | 描画セクション | 1 AU あたりの描画ユニット数（距離スケール） |
| `PHYS_DT` | 物理セクション | 物理積分の固定タイムステップ（デフォルト 0.5 日） |
| `BODIES[].radius` | 天体データ | 各天体の表示用半径（見やすさ優先） |
| `TRAIL_MAX` | 描画セクション | 軌道トレイルの最大頂点数 |

## 技術スタック

- **Three.js 版**: [Three.js](https://threejs.org/) 0.161.0（ES Module / importmap 経由で CDN 読み込み）
- **WebGPU 版**: WebGPU API + WGSL シェーダ。行列演算・球メッシュ・カメラ操作（OrbitControls 相当）まで外部ライブラリなしで自前実装
- いずれも外部ビルドツール不要のバニラ HTML + JavaScript
- 初期天体データ: NASA/JPL HORIZONS（J2000 元期の状態ベクトル）
