# 太陽系シミュレーター

太陽系の8惑星と太陽の運動を、実際の物理値に基づいてシミュレートする単一HTMLアプリケーションです。
ブラウザで [`solar_system.html`](solar_system.html) を開くだけで動作します。

![type](https://img.shields.io/badge/type-single--file-blue) ![deps](https://img.shields.io/badge/Three.js-0.161.0-green)

## 動作環境

- モダンなブラウザ（Chrome / Edge / Firefox / Safari）
- インターネット接続（Three.js を CDN から `importmap` で読み込むため）

サーバーは不要。`solar_system.html` をダブルクリックして開くだけです。

## 操作方法

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 視点の回転 |
| 右ドラッグ | 視点の平行移動（パン） |
| マウスホイール | 拡大・縮小（ズーム） |

### 画面左上のUI

- **日付表示** — 現在のシミュレーション時刻に対応する実日付（`YYYY年MM月DD日`）
- **経過年数** — 元期 (J2000) からの経過年数
- **シミュレーション速度スライダー** — 実時間1秒あたりに進む年数を対数で調整（**約 0.01 〜 1000 年/秒**、デフォルト **1秒 = 1年**）
- **⏸ 一時停止 / ▶ 再生**
- **↺ リセット** — 初期状態（元期）に戻す
- **重力伝播遅延** — 光速での重力伝播遅延の ON/OFF（デフォルト ON）
- **軌道トレイル表示** — 軌跡の表示 ON/OFF

## 仕様

### 物理シミュレーション

- **初期状態**: J2000 元期（2000-01-01 12:00 TT）における各天体のヘリオセントリック位置・速度。NASA HORIZONS 由来の近似値を使用。
- **質量**: 太陽および各惑星の実際の質量 (kg) を使用。
- **重力**: ニュートンの万有引力（万有引力定数 G = 6.674×10⁻¹¹）。
- **積分法**: velocity Verlet（リープフロッグ）、固定タイムステップ **0.5 日**。
- **重力伝播遅延**: 各天体の位置履歴をリングバッファで保持し、`距離 / 光速` だけ過去の位置から受ける力を計算。
- **運動量保存**: 系全体の運動量がゼロ（重心が静止）になるよう、太陽の初速で全運動量を相殺。

### 表示

- **距離スケール**: 実距離を反映（1 AU = 40 描画ユニット）。
- **惑星サイズ**: 見やすさを優先し、実スケールではなく誇張した半径で描画。
- **見た目**: 手続き的に生成したテクスチャ（斑点、木星・土星の縞模様）、土星の環、太陽のグロー、星空背景、軌道トレイル、惑星名ラベル。
- **自転**: 見栄え用の固定速度で回転（実際の自転周期ではない）。

### 含まれる天体

太陽、水星、金星、地球、火星、木星、土星、天王星、海王星（衛星は含まない）。

## 既知の制約（意図的な割り切り）

物理シミュレーションは簡易実装として割り切っています。

- 初期軌道要素は元期スナップショットの近似値のため、長期間積分すると実際の天体暦から徐々にずれます。
- 重力伝播遅延は「現在位置で距離を見積もってから遅延位置を参照する」一次近似です（反復解は行いません）。
- 惑星の自転は実際の自転周期を反映していません。

## カスタマイズの目安（ソース内の定数）

| 定数 | 場所 | 意味 |
|------|------|------|
| `SCALE` | 描画セクション | 1 AU あたりの描画ユニット数（距離スケール） |
| `PHYS_DT` | 物理セクション | 物理積分の固定タイムステップ（デフォルト 0.5 日） |
| `BODIES[].radius` | 天体データ | 各天体の表示用半径（見やすさ優先） |
| `TRAIL_MAX` | 描画セクション | 軌道トレイルの最大頂点数 |
